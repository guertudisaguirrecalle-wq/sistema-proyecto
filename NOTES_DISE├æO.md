# Plan de diseño (referencia interna)

## Paleta
--color-bg: #FBF7F4       blanco cálido (fondo principal)
--color-bg-alt: #F6EFE9   crema (secciones alternas)
--color-surface: #FFFFFF  blanco puro (tarjetas)
--color-rose: #F0D9D6     rosa pastel (fondos suaves, badges)
--color-rose-deep: #C98B92 rosa empolvado profundo (CTAs, acentos)
--color-lilac: #E4DBF2    lavanda pastel (fondos suaves)
--color-lilac-deep: #A996C9 lila profundo (hover, acentos secundarios)
--color-champagne: #E9DFC7 champán (bordes, líneas)
--color-nude: #D9C2AC     nude (tags, detalles)
--color-text: #3A2E30     carbón cálido casi negro
--color-text-soft: #8A7A7D gris malva (texto secundario)
--color-success: #8FAE8B
--color-danger: #C97B7B

## Tipografía
- Display (títulos): 'Fraunces' (serif editorial, con personalidad de moda)
- Cuerpo: 'Manrope' (sans moderna, legible)
- Eyebrow/labels: Manrope uppercase, letter-spacing amplio

## Firma visual
- Blobs orgánicos SVG en degradé rosa/lila detrás de imágenes
- Monograma "CB" entrelazado como marca
- Pills redondeadas para categorías y tallas
- Líneas finas doradas/champán como divisores
